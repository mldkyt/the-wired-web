# Forgejo

The Forgejo instance is available for anyone to sign up at, for anything from hosting code to forking other people's projects.

You can register using an [Akkoma](https://the-wired.club) account on The Wired, [Codeberg](https://codeberg.org), [git.gay](https://git.gay), [Discord](https://discord.com) or [GitHub](https://github.com). By default nothing will be migrated and the integrations will be purely used to authenticate you.

## Rules

We have some basic rules just to get the worst of the worst out

1. common sense
2. don't abuse the limited resources of this instance
